How ResolveIT Works

A transparent, transparent 4-stage lifecycle ensuring every student grievance is tracked to verified resolution.

1

Submit Online

Authenticate securely, choose the facility category, specify location, and provide details. A unique tracking ID is generated instantly.

2

Automated Triage

The request is routed to Cloud Firestore. Facility administrators and department technicians receive the complaint in their dashboard.

3

Action & Resolution

Staff updates the status to 'In Progress', dispatches maintenance, logs official resolution notes, and marks the task as 'Resolved'.

Cloud Computing Architecture

Built adhering to modern cloud principles: decoupled frontend hosting and serverless database backends.

☁

Frontend Edge Hosting

Hosted on AWS Amplify or Azure Static Web Apps with global Content Delivery Network (CDN) distribution, automatic SSL certificate provisioning, and fast static delivery.

🔒

Firebase Authentication

Secured via tokenized JWT session management. Enforces strict role-based authorization separating standard students from facility administrators.

💾

Cloud Firestore

Scalable NoSQL cloud database storing complaint collections with granular security rules preventing unauthorized data tampering.
